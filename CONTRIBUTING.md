# Contributing to Chariot Security

Thank you for your interest in contributing! 🎉

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork
3. **Create** a feature branch
4. **Make** your changes
5. **Test** thoroughly
6. **Commit** with clear messages
7. **Push** to your fork
8. **Open** a Pull Request

## Development Setup

See [README.md](README.md#getting-started) for setup instructions.

## Code Style

- **Python:** PEP 8
- **JavaScript/TypeScript:** ESLint configuration
- **Commits:** Conventional Commits format

## Commit Message Format

\\\
<type>: <subject>

<body>

<footer>
\\\

**Types:**
- feat: New feature
- fix: Bug fix
- docs: Documentation
- style: Formatting
- refactor: Code restructuring
- test: Tests
- chore: Maintenance

**Examples:**
\\\
feat: add fraud detection model
fix: resolve authentication bug
docs: update API documentation
\\\

## Pull Request Guidelines

- One feature per PR
- Update documentation
- Add tests if applicable
- Link related issues
- Request review from team

## Questions?

Contact the team or open an issue!
